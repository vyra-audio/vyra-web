Two decks.
One focused workspace.

Vyra is a local-first, open-source DJ mixing application for the desktop, written in C++20 with JUCE. Two decks, a SQLite music library, three-band channel EQ, MIDI Learn and 24-bit recording — with no cloud service between you and your files.

Vyra is not yet a replacement for mature commercial DJ systems. Read the current limitations before using it for a performance.

Features

What is actually in the source

Vyra is a small, deliberate application rather than a feature checklist. Everything below exists in the current tree and is described in the README or the technical docs.

Mix and perform

Two decks, a channel strip each, and a master bus that records.

  • Two independent decks

    Asynchronous track loading, play/pause, cue and seek on both decks, each with a compact overview waveform. Click or drag the overview to seek; double-click it to load another track.

  • Hot cues and loops

    Three saved hot cues per track, 1/2/4/8-beat region loops, four-beat forward and backward jumps, and pitch adjustment up to ±16%. Cue points and loop length are remembered with the track.

  • Channel strip

    Per deck: three-band EQ, a resonant filter, echo, channel gain and a level meter. The EQ maps a full MIDI sweep to −12 dB through +12 dB.

  • Master section

    An equal-power crossfader, master gain, a bounded peak limiter and an output meter, mixed from two stereo deck buffers.

  • Record the set

    Capture the limited master output to a 24-bit stereo WAV file, with pause and resume. Encoding runs on a worker path, never inside the audio callback.

  • Headphone cue

    Pre-fader deck monitoring with a cue/master mix, on audio devices that expose four or more outputs. The headphone output pair is selectable in Settings.

Organize the library

A local SQLite database, not a cloud catalogue.

  • Local music library

    Import folders into a SQLite library that keeps embedded metadata and cached waveform peaks. Tracks opened straight from disk still appear in the history.

  • Search, playlists and history

    Search title, artist, album, genre or path. Build named playlists with duplicate-safe add and remove, and review recent plays with timestamps and deck attribution.

  • BPM and key estimates

    Automatic tempo and chroma-based key estimates when embedded metadata is missing, plus BPM display, beat jumps and one-shot sync on the decks. These are estimates, not editable beat grids.

Controllers, devices and integrations

Standard MIDI input, explicit about what it does not cover.

  • MIDI Learn

    Pick any MIDI input the operating system exposes, choose an action, press Learn, then move the control. An existing duplicate assignment is replaced, so one control never drives two actions.

  • Mapping depth

    Buttons learn MIDI notes, knobs and faders learn 7-bit CC, and continuous actions accept 14-bit pitch bend. A jog wheel maps to a relative seek nudge — 20 ms per tick, not scratch emulation.

  • Portable maps

    Export assignments as a versioned JSON file and import them on another machine. Imports are validated before they replace the current map; malformed or duplicate entries are rejected.

  • Starter profiles

    Four small starter mappings: Numark Party Mix, Pioneer DDJ-400, Pioneer DDJ-FLX4 and Hercules DJControl Inpulse 500. Other controls can be assigned with MIDI Learn.

  • Audio device settings

    Choose the audio backend and output device, and see the active sample rate and buffer size. Headphone routing appears when the device exposes enough outputs.

  • Discord Rich Presence

    Optional and on by default: shares the active deck's title and playback progress with the local Discord desktop client. It can be switched off in Settings.

Controllers

Any MIDI input, mapped by hand

Vyra follows the standard MIDI input protocol rather than a vendor driver, and lets you build the mapping yourself instead of promising pre-mapped hardware.

  1. 01

    Select the input

    Open Settings → MIDI Controller and choose any MIDI input your system lists.

  2. 02

    Learn one action

    Pick an action, press Learn, then press the button or move the fader you want to use.

  3. 03

    Keep the map

    Assignments persist in the Vyra settings file, and export to JSON for another machine.

Learnable actions include play, cue, three hot cues, loop toggle, beat jump, one-shot sync, headphone cue, pitch, the three EQ bands, filter, echo, crossfader, channel level and master gain.

Status and limits

Early development, stated plainly

Vyra is an actively developed foundation for a two-deck DJ application. The roadmap describes targets, not finished work — every item below is a known limit of the current tree.

Current limitations

  • Two-deck operation only. Four decks are not implemented.
  • Pitch changes playback speed and pitch together; there is no key lock or time stretching.
  • BPM and key are automatic estimates. Editable beat grids and beat-aligned continuous sync do not exist yet.
  • MIDI jog is a relative seek nudge, not scratch emulation. HID, LED feedback, MIDI output and DVS/timecode are absent.
  • Supported audio formats depend on the JUCE build and the format modules enabled.
  • Backends, routing and latency depend on the platform and drivers; no latency figure or hardware compatibility is claimed.
  • Missing library files are flagged, but relinking is not implemented yet.
  • The audio callback has not been benchmarked for worst-case latency. This is a functional audio foundation, not a latency certification.

Next milestones

  1. Audio callback stress and latency tests, safe source replacement, device-change recovery, supported-format verification.
  2. Better BPM and key analysis, editable beat grids, beat-aware sync, quantise, key-locked time-stretch, scratch-grade jog control.
  3. Headphone routing validation across drivers, improved EQ, filter and effects, extensible effect interfaces.
  4. Recording export formats and metadata, MIDI output and LED feedback, hardware verification.
  5. Four-deck mode, workspace persistence and layouts, themes, recovery, release packages and cross-platform verification.

Build

From source, in three commands

Vyra has no installer on this page. The supported path is a CMake build with a C++20 toolchain; dependencies are fetched and pinned on the first configure.

Requirements

  • CMake 3.22 or later.
  • A C++20 compiler and a native desktop/audio development toolchain.
  • Git and network access for the initial configure, which fetches pinned dependencies.
  • JUCE 7.0.12 is pinned. Set -DVYRA_USE_SYSTEM_JUCE=ON to use an installed JUCE CMake package instead.

After the build

The executable is placed under build/Vyra_artefacts/Release/ (Vyra.exe on Windows). Run the test suites with ctest --test-dir build --output-on-failure, adding -C Release on multi-configuration generators.

Windows · PowerShell 
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
Linux and macOS 
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build --output-on-failure
